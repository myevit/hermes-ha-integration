# Minimal public engine extraction

This change extracts the already-qualified single-model Engine, NativeLoop,
Sessions, genuine PluginContext Host and finite policy/capability library into
an optional installable package beside the transport. It is not a second engine.
The exact completed-item acknowledgement and finish_turn protocol is retained.

Parameterize the genuine named owner from PluginContext; keep SessionDB's normal
profile constructor, MemoryManager and configured Mnemosyne provider. No persona,
policy, credentials, private paths, session rows or default admin grants ship.
Separate generic policy validation from owner-specific reviewed switch grants.
The latter must be explicit policy input; an example contains only fictional
standard HA targets and is not approved for use.

Extract only PCM conversion and the subscription signing/wire subset needed from
the MIT Talk dependency, preserving its license and provenance. Do not vendor its
UI, unrelated auth lanes or monolithic backend. Hermes signs for the owning
profile; no token-file reads or silent default-root credential escalation.
Install a tiny profile plugin shim from the wheel so the supported signed-provider
API can identify an installed plugin frame and its requires_auth declaration.

Qualification must install built wheels in an isolated environment, run genuine
loader/factory/Host/SessionDB/MemoryManager/Mnemosyne/Engine with synthetic provider
and MCP network seams only, and scan import origins for private dependencies.
Load production policy read-only only into an isolated qualification profile;
never open production databases or dispatch real tools. Preserve the observed
native/text catalog relationship rather than hard-coding its size as permission.
Run unit and real HA baseline/current fixtures, scan new diff and reachable public
history, push only the fork and read back remote SHA. Existing security review
is partial, not a clean security certification.

No activation is authorized. A future exact approval includes one HA restart and
one same-owner service cycle, managed credentials/trusted TLS, bounded provider /
physical capture / Piper acceptance, then separately approved decommissioning.
